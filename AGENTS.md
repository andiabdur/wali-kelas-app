# AGENTS.md - Workspace Mandatory Rules

## Rule 1: Zero Emoji Usage
- Never use emojis anywhere in the codebase, UI components, toast alerts, data structures, or labels.
- Always use vector icons (`lucide-react` SVG icons) for visual indications.

## Rule 2: Premium UI/UX & Design Authenticity
- Always use high-quality UI/UX design standards. Never produce generic "AI slop" or basic default layouts.
- Use modern web guidance skills, clean spacing, Framer Motion micro-interactions, responsive spring physics, dark mode tokens, and professional typography.
