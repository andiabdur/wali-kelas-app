# Project Rules & Design Guidelines

## Rule 1: No Emojis in Code or UI (Strict Mandate)
- DO NOT use any emoji characters anywhere in the codebase, UI elements, labels, buttons, or toast notifications.
- Always use professional vector SVG icons (e.g. `lucide-react`) for all visual representations.
- All toast notifications, tooltips, and text strings must be clean, professional, and emoji-free.

## Rule 2: Authentic, Professional UI/UX Standards (No "AI Slop")
- UI design must draw inspiration from top-tier professional design systems (e.g., Apple Human Interface Guidelines, Tailwind UI, modern clean dashboards).
- Avoid generic, basic, or unstyled UI patterns ("AI slop").
- Implement smooth micro-interactions, responsive hover/active spring physics (Framer Motion), clean typography (Inter / Plus Jakarta Sans), crisp shadows, and harmonious color tokens.
- Maintain consistent spacing, alignment, and accessible contrast ratios across light and dark modes.
